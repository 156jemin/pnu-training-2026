# 2026 부산대학교 직무연수 안내 포털 (PNU Job Training Portal 2026)

국립 부산대학교 교직원 역량 개발을 위한 2026년도 직무연수 종합 안내 웹사이트입니다.

## 🌟 주요 특징
- **구글 스프레드시트 실시간 연동**: `gviz/tq` API와 `PapaParse`를 활용하여 구글 시트의 수정 내용이 새로고침 시 즉시 반영되는 완전 무서버(Serverless) 정적 웹사이트
- **다차원 복합 검색 & 필터링**: 10개 직무 분야 탭, 대상(전 직원/실무자/관리자/신규자), 이수구분(필수/권장/선택), 교육방식, 신청상태 실시간 교집합 필터링
- **스마트 검색어 하이라이트**: 연수명, 코드, 담당부서, 커리큘럼 키워드 실시간 하이라이팅
- **반응형 2페이지 구조**:
  - `index.html`: 메인 연수 카탈로그, 히어로 메트릭 통계, 다차원 필터, 카드 그리드
  - `detail.html`: 과정 상세 안내, 6종 스펙, 학습목표 체크포인트, 커리큘럼 카드, 수강신청 액션바 및 링크 복사
- **디자인 아이덴티티**: 부산대학교 PNU Ocean Blue(` #003B80`), PNU Deep Navy(` #0B1E36`), Pretendard 타이포그래피 기반의 정제된 아카데믹 모더니즘 UI

## 📁 디렉토리 구조
```
├── index.html           # 메인 페이지 (검색, 필터, 연수 카드 그리드)
├── detail.html          # 상세 페이지 (커리큘럼, 학습목표, 수강신청)
├── css/
│   ├── base.css         # 전역 리셋, 디자인 토큰, Pretendard 웹폰트
│   ├── components.css   # 헤더, 푸터, 뱃지, 카드, 스켈레톤, 버튼
│   ├── main.css         # 메인 페이지 그리드 & 필터 바
│   └── detail.css       # 상세 페이지 2단 레이아웃 & 플로팅 사이드바
├── js/
│   ├── api.js           # Google Sheets CSV 실시간 비동기 연동 및 캐시 버스팅
│   ├── filter.js        # 실시간 검색 및 다차원 복합 필터 엔진
│   ├── main.js          # index.html 컨트롤러 및 URL 쿼리 파라미터 동기화
│   ├── detail.js        # detail.html 컨트롤러 및 파라미터 렌더링
│   └── mockData.js      # 오프라인 및 시트 오류 대응 백업 데이터
└── PROJECT_PLAN.md      # 작업 기획서
```
